# vsm-dfig-robust-tuning

Reproducibility package for the paper:

> **Multi-Objective Optimisation for Robust Control of VSM-DFIG Wind Farms in Weak Grids**
> J. García-Aguilar, A. García-Cerrada, J. L. Zamora and A. Tomás-Martín
> Institute for Research in Technology, Comillas Pontifical University, Madrid, Spain

Every figure, table and numerical claim in the paper is produced by the code in this
repository. Nothing reported in the paper is obtained by any other route.

Two quantities do not reproduce to round-off, and in both cases the cause is identified rather
than tolerated — they are stated in [`REPRODUCE/README.md`](REPRODUCE/README.md) and in the files
that carry the affected numbers. Everything else agrees to better than 1 %.

---

## How this repository is organised

| Path | Contents |
|---|---|
| [`REPRODUCE/`](REPRODUCE/) | **One file per result of the paper.** Each file states the exact procedure for that figure or table: prerequisites, settings, the script to run, the expected output and the expected values. Start here. |
| `SIMULINK/` | `POWER_SYSTEM_FULL.slx` — the four-machine DFIG wind-farm benchmark of Section 2 |
| `CONFIGURATION/` | Benchmark parameters (Table 1), operating-point definition, run driver, paper-figure generators |
| `MODEL/` | Machine, converter, drivetrain and external-grid models (Sections 2.1–2.4) |
| `CONTROL/` | Coordinated frequency-response design, CFRD (Section 2.5) |
| `ANALYSIS/` | Operating-point solve, linearisation, eigenvalue and per-band damping analysis (Section 3) |
| `OPTIMIZATION/` | Five-phase NSGA-II workflow over design specifications (Section 4) |
| `SIMULATION/` | Nonlinear time-domain studies and the symmetric-fault campaign (Section 6) |
| `FIGURES/`, `PLOT_FILES/` | Plotting utilities |
| `BUS_DEFINITIONS/` | Simulink bus objects |

Simulation outputs are **not** version-controlled. They are regenerated by the procedures in
[`REPRODUCE/`](REPRODUCE/).

## Quick start

```matlab
cd CONFIGURATION
CONFIG_POWER_SYSTEM      % RUN_MODE = 0 solves the operating point and linearises
```

`CONFIG_POWER_SYSTEM.m` is the single driver for the whole study. Its behaviour is set by three
switches declared at the top of the file:

| Switch | Meaning |
|---|---|
| `RUN_MODE` | 0 operating point · 1 linear analysis at endpoints · 2 linear analysis over the envelope · 3 GA optimisation · 4 nonlinear simulation · 5 optimum design sequence |
| `CONTROL_TYPE` | 1 time-response design · 2 frequency-response design (CFRD, the paper's baseline) · 3–7 GA variants |
| `OPT_SEQUENCE` | Optimisation phases to execute, `[1 2 3 4 5]` = Phases 1–5 of Section 4.2 |

Each file in [`REPRODUCE/`](REPRODUCE/) states the values these switches must take.

## Reproducibility notes

- **Model checksum, and why the file here does not match the published one.** The results in the
  paper were produced with `POWER_SYSTEM_FULL.slx`, md5 `04fba8fce3bf38c5600f2f894fe3d6b0`. The
  copy here is md5 `a62ae9d3963e7a92bd0d776dd3b60418` because its document metadata was cleared
  of two author usernames before publication. All 36 other archive entries are byte-identical —
  only `metadata/coreProperties.xml` differs — and the 84 blocks and 3 subsystems are unchanged
  and were verified by loading it. **Check against `a62ae9d3…`, not against the published value —
  and check it BEFORE you run anything.** The model is stored in R2025a format, so the first time
  a newer MATLAB opens and saves it the file is rewritten and a `POWER_SYSTEM_FULL.slx.r2025a`
  backup appears beside it. Measured on R2026a after one GA phase, the md5 becomes
  `9d8bd55e746462947c0e2d8610ba8ed6`. That is a format rewrite, not a model change, and it is
  expected — but a checksum taken afterwards will not match and is not evidence of anything.
  `git checkout SIMULINK/POWER_SYSTEM_FULL.slx` restores the shipped file.
- **Two model configurations, and they must not be mixed.** The *design* configuration carries
  no active limiting or protection and produces the optimisation and every small-signal result.
  The *verification* configuration arms the converter current limiters, the DC-link chopper and
  the RSC derate, and is used only by the symmetric-fault campaign of Section 6.3. Section 2.2 of
  the paper states which configuration produced which result; so does each file in `REPRODUCE/`.
- **Determinism.** The genetic algorithm is stochastic. Seeds are fixed and stated per result.
  Section 5.7 of the paper reports the measured sensitivity to the solver seed.
- **Per-unit convention.** Base voltage `U_b = 690 V` (line-to-line rms), base current
  `I_b = 1760 A` (phase rms), hence `S_b = sqrt(3)·U_b·I_b = 2.1034 MVA`,
  `Z_b = U_b/I_b = 0.3920 Ω` and `L_b = Z_b/ω_b = 1.2479 mH` with `f_0 = 50 Hz`.
  This base is `sqrt(3)` times the star phase-impedance base of the reference textbook, so every
  per-unit impedance here is `1/sqrt(3)` of the corresponding value there.
